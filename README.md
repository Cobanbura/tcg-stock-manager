# TCG Stock Manager

A modular browser-based Shopify CSV editor and stock modifier designed for Trading Card Game (TCG) sellers.

## 🚀 Features
- ⚡ **100% Client-Side:** Processes data directly in your browser using Vanilla JavaScript (ES6 Modules). Your inventory data never leaves your computer.
- 🧩 **Modular Architecture:** Designed to easily adapt to different TCG systems.
- 🏷️ **Shopify Ready:** Preserves Shopify CSV structure and tags while updating stock levels and price variants.
